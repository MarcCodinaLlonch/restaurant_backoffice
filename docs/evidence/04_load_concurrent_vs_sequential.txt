# Interpretació (mesures repetides 3 vegades, resultats estables):
# - SQLite:     concurrent ~0,41 s  vs  seqüencial ~0,29-0,36 s  -> la concurrència NO hi guanya.
#   SQLite és una llibreria dins del mateix procés: les consultes són CPU (amb el GIL agafat),
#   no esperen cap socket. No hi ha esperes per solapar i to_thread + Semaphore només afegeixen cost.
# - PostgreSQL: concurrent ~0,45 s  vs  seqüencial ~0,69 s  -> la concurrència guanya (~1,5x).
#   Cada consulta espera la resposta de PostgreSQL per xarxa; mentre un fil espera, els altres avancen.
# - El benefici de la concurrència apareix quan hi ha ESPERES (xarxa, BD, clients lents):
#   vegeu 03_p1_vs_p2.txt (client inactiu) i 02_experiment_db.txt (BD lenta).
